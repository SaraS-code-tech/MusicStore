# About my project
It's still an ongoing project, so not all the intended functionalities have been implemented yet.

Despite the project not being complete, it is designed to be a website for a hypothetical music store where users can buy CDs, vinyl records, and merchandise. Users can browse all products or search for specific items of interest. Once a product is selected, its details are displayed.
The website includes a shopping cart and all the typical features of an online store. There is also the option to create an account or shop as a guest, with the possibility of saving the cart between sessions or not.

No real transactions will take place, as everything is purely hypothetical.
